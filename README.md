# Customer Behavior Analysis

An end-to-end data analysis project exploring retail sales performance, customer purchasing behavior, and customer satisfaction using Python, PostgreSQL, and Power BI.

The project uses retail transaction data to investigate revenue trends across product categories, products, regions, and seasons, as well as differences in customer spending and review ratings. The goal is to identify business patterns and generate insights that could support data-driven decision-making.

Data is from Kaggle https://www.kaggle.com/datasets/timcii/clothing-store-sales-data?resource=download 

**Tools & Technologies**
- **Python (pandas):** Data cleaning, preprocessing, and data quality checks
- **PostgreSQL:** Data storage, querying, aggregation, and exploratory analysis using SQL
- **Power BI:** Interactive dashboard development and data visualization *(in progress)*

**Project Status:** In Progress
