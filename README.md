# Customer Behavior Analysis

An end-to-end data analysis project exploring retail sales performance, customer purchasing behavior, and customer satisfaction using Python, PostgreSQL, and Power BI.

Data is from Kaggle https://www.kaggle.com/datasets/timcii/clothing-store-sales-data?resource=download 

The dataset contains simulated data representing information on more than 100 000 purchase transaction from an e-commerce platform during the period of January 2022 to December 2024.

The project uses retail transaction data to investigate revenue trends across product categories, products, and regions, as well as differences in customer spending and review ratings. The goal is to identify business patterns and generate insights that could support data-driven decision-making.

**Tools & Technologies**
- **Python (pandas):** Data cleaning, preprocessing, and data quality checks
- **PostgreSQL:** Data storage, querying, aggregation, and exploratory analysis using SQL
- **Power BI:** Interactive dashboard development and data visualization

**Project Status:** Completed
